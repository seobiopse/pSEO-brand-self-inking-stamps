⚙️ Rendering Requirement — Server-Side Only
❌ WRONG — CSR / Client-Side Render
<!-- Raw HTML Googlebot crawls -->
<title>{{category_name}} | Buy Online...</title>
<meta name="description" content="Shop {{category_name}}...">
<h1>{{category_name}}</h1>
<p>...from {{min_price}}, choose from {{total_products_count}}...</p>

→ Googlebot sees empty shells.
→ Indexed as thin / duplicate content.
→ pSEO strategy fails entirely.
✅ CORRECT — SSR / Pre-rendered HTML
<!-- Raw HTML Googlebot crawls -->
<title>DF Self Inking Rubber Stamps | Buy Online...</title>
<meta name="description" content="Shop DF Self Inking Rubber Stamps...">
<h1>DF Self Inking Rubber Stamps</h1>
<p>...from $30.00, choose from 31...</p>

→ Googlebot reads full content.
→ Each page indexed as unique.
→ pSEO strategy executes correctly.
How variables must be injected — by stack: PHP / Laravel     echo str_replace('{{category_name}}', $product->category_name, $template);
Blade template   {{ $product->category_name }} — resolves server-side before HTML sent to browser
Next.js           getServerSideProps() or generateStaticParams() — never useEffect or client fetch
WordPress        the_title() / get_post_meta() — in PHP template file, not JS

Never inject pSEO content via: fetch() on mount · useEffect · document.innerHTML · React state on load · any JS running after DOMContentLoaded
